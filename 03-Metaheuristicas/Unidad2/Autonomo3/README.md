# Autonomo 3 — Simulated Annealing y Tabu Search

Requisitos: Python 3.8+

Pasos para ejecutar:

1. Abrir una terminal en la carpeta `03-Metaheuristicas/Unidad2/Autonomo3`.
2. Ejecutar:

```bash
python run_experiments.py
```

El script generará `results_autonomo3.csv` con los resultados de varias corridas.

Puedes ajustar parámetros en `run_experiments.py` para cambiar número de corridas, iteraciones, etc.
