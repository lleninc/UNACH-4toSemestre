📚 Documentación del Sistema

Guía completa del Sistema de Análisis de Jobs de Backup

🏠 Inicio 📊 Análisis 🔮 Predicciones 📚 Documentación

🎯 Objetivo del Sistema

Este sistema analiza jobs de backup del dataset backup1.csv para:

  • Identificar patrones de éxito y falla en jobs de backup
  • Reducir el número de jobs con error mediante análisis predictivo
  • Proporcionar insights accionables para optimizar el sistema
  • Monitorear el rendimiento general del sistema de backup

🔢 Interpretación de Códigos de Status

El dataset backup1.csv utiliza códigos numéricos para representar el estado de los jobs:

Código Significado Descripción Acción Requerida
0 ✅ Éxito Job completado satisfactoriamente Ninguna - Mantener configuración
> 0 ❌ Error Job falló con código específico Investigar causa del error

Ejemplos de códigos de error comunes:

  • Código 1: Error general de job
  • Código 2: Error de conexión
  • Código 3: Error de permisos
  • Código 4: Error de recursos
  • Nota: Los códigos específicos varían según la implementación del sistema

📊 Estructura del Dataset

El archivo backup1.csv contiene las siguientes columnas principales:

Columna Descripción Ejemplo
Job Id Identificador único del job 556702
Type Tipo de job de backup Backup, Replication, Snapshot
Status Código numérico de resultado 0, 1, 2, 3, ...
State Estado del job durante ejecución Queued, Active, Done
Media Server Servidor que ejecuta el job ecbplxnbp10, precanf008
Job Schedule Programación del job Diferencial_Diario, Incremental_Diario

🚀 Cómo Usar el Sistema

1. Dashboard Principal

La página principal muestra un resumen con:

  • Total de jobs analizados
  • Número de jobs exitosos y con error
  • Tasas de éxito y error
  • Recomendaciones basadas en el análisis

2. Análisis Detallado

La sección de análisis proporciona:

  • Gráficos de distribución de códigos de status
  • Análisis de códigos de error específicos
  • Distribución por tipos de jobs
  • Tablas detalladas con estadísticas

3. Sistema de Predicciones

Permite evaluar la probabilidad de éxito de un job mediante:

  • Selección del tipo de job
  • Especificación del media server
  • Configuración de la programación
  • Obtención de predicción con nivel de confianza

🔧 APIs Disponibles

El sistema proporciona APIs REST para integración programática:

GET /api/stats

Obtiene estadísticas generales del dataset Respuesta: JSON con total_jobs, success_jobs, error_jobs, etc.

POST /api/predict

Realiza predicción para un job específico Body: {"job_type": "Backup", "media_server": "ecbplxnbp10", "job_schedule": "Diferencial_Diario"} Respuesta: {"prediction": "Éxito", "confidence": 95.2, "reason": "..."}

📈 Interpretación de Resultados

Tasas de Error

  • < 1%: ✅ Excelente - Sistema funcionando óptimamente
  • 1-5%: ⚠️ Aceptable - Monitoreo recomendado
  • > 5%: 🚨 Crítico - Revisión urgente necesaria

Niveles de Confianza en Predicciones

  • > 80%: Alta confianza - Predicción muy confiable
  • 50-80%: Confianza media - Predicción moderadamente confiable
  • < 50%: Baja confianza - Requiere análisis adicional
