1.1 · CONCEPTO
Concepto y Tipos de ML
▼
Definición ISO (2023): El aprendizaje automático desarrolla algoritmos capaces de mejorar su desempeño en tareas específicas a partir de datos, sin ser programados explícitamente para cada caso.
vs Programación tradicional: Programación → el humano escribe las reglas. ML → el algoritmo aprende las reglas a partir de los datos.
🏷️
1. Supervisado
Datos con etiquetas conocidas. El más usado.

Ej: spam, diagnóstico médico, predicción de precios.
🔍
2. No Supervisado
Sin etiquetas. Descubre estructuras ocultas.

Ej: clustering de clientes, PCA, análisis de redes.
🔀
3. Semi-supervisado
Pocos etiquetados + muchos sin etiquetar.

Ej: genómica, Google Photos.
🎮
4. Por Refuerzo
Recompensas y penalizaciones al interactuar con entorno.

Ej: robot caminando, videojuegos.
🧠
5. Auto-supervisado
Genera sus propias etiquetas desde los datos.

Ej: GPT, BERT, LLMs.
🔗
Sistemas Híbridos
Combinan múltiples paradigmas. Arquitecturas más robustas y versátiles.

2.1 · FLUJO DE PROYECTO
Flujo de un Proyecto de ML
▼
Idea central: el flujo NO es lineal. Se vuelve a etapas anteriores si los datos son malos, la métrica es baja o el modelo no generaliza.
EtapaQué se hacePor qué importa
1. Definición del problema¿Qué se quiere predecir?Evita metas ambiguas
2. Exploración de datosPatrones, errores, variables claveEntiende calidad del dataset
3. PreprocesamientoFaltantes, ruido, escalado, codificaciónMejora la entrada al modelo
4. División de datosTrain / Val / TestEvita evaluar con datos ya vistos
5. EntrenamientoEl algoritmo aprende relacionesConstruye el modelo
6. ValidaciónAjuste de hiperparámetrosElige el mejor modelo
7. EvaluaciónMétricas sobre datos nuevosIndica desempeño real
8. DespliegueModelo en contexto realConvierte el modelo en solución
Conjuntos: Entrenamiento → aprende patrones. Validación → ajusta hiperparámetros. Prueba → se usa UNA SOLA VEZ al final.
📊
2.2 · MÉTRICAS
Accuracy, Precision, Recall, F1, RMSE
▼
Matriz de confusión: VP (correctos positivos), VN (correctos negativos), FP (falso positivo), FN (falso negativo).
🎯
Accuracy
(VP+VN)/Total.
Útil solo con clases BALANCEADAS.
Puede engañar con clases dominantes.
🔬
Precision
VP/(VP+FP).
Útil cuando FP es costoso.
Ej: spam → no perder correos legítimos.
🩺
Recall
VP/(VP+FN).
Útil cuando FN es costoso.
Ej: medicina → no perder enfermos reales.
⚖️
F1-score
2·(P·R)/(P+R).
Equilibrio entre precision y recall.
Ideal con datos DESBALANCEADOS.
📉
RMSE
√(Σ(y−ŷ)²/n).
Para REGRESIÓN, no clasificación.
Más bajo = mejor ajuste.
✂️
2.3 · VALIDACIÓN CRUZADA
División de Datos y K-Fold
▼
ProporcionesCuándo usar
80/20 (Train/Test)Casos simples o datasets pequeños
70/15/15 (Train/Val/Test)Proyectos académicos y prototipos
60/20/20 (Train/Val/Test)Cuando se quiere validación más clara
K-Fold Cross-Validation: Divide en k partes → entrena en k-1 → valida en la restante → repite k veces → promedia resultados. Estimación más estable.
Regla de oro: El conjunto de PRUEBA no debe usarse para ajustar el modelo. Solo se consulta al final, UNA SOLA VEZ.
⚖️
2.4 · SESGO Y VARIANZA
Sobreajuste y Subajuste
▼
SituaciónError TrainError ValCausa
✅ Buen ajusteBajoBajoGeneraliza bien
🔴 SobreajusteMuy bajoAltoMemoriza, no generaliza
🟡 SubajusteAltoAltoModelo demasiado simple
🔴
Sobreajuste (Overfitting)
Varianza alta. Soluciones: más datos, simplificar modelo, regularización, validación cruzada, early stopping.
🟡
Subajuste (Underfitting)
Sesgo alto. Soluciones: modelo más complejo, más variables, más epochs, menos restricciones.
Sesgo-Varianza: Sesgo alto → subajuste. Varianza alta → sobreajuste. El objetivo es encontrar el equilibrio óptimo.
🔑
RESUMEN · T2
Lo que debes recordar para el quiz
▼
  • El flujo de ML no es lineal; se itera entre etapas cuando los datos o métricas fallan.
  • Accuracy puede engañar si una clase domina el dataset → usa F1-score en esos casos.
  • Precision → cuando FP es costoso (spam). Recall → cuando FN es costoso (medicina, fraude).
  • F1-score = equilibrio entre Precision y Recall. Útil con datos desbalanceados.
  • RMSE → solo para regresión (valores continuos), no para clasificación.
  • Conjunto de prueba = se usa una sola vez al final. No para ajustar hiperparámetros.
  • K-Fold da estimación más estable del desempeño pero cuesta más tiempo de cómputo.
  • Sobreajuste: bajo error en train, alto en val → memoriza, no generaliza → varianza alta.
  • Subajuste: alto error en ambos → modelo demasiado simple → sesgo alto.

Regresión Lineal, Polinómica y Regularizada
▼
REGRESIÓN LINEAL
Propósito: Estimar una variable de salida ŷ como combinación lineal de un conjunto de predictores x₁, x₂, ..., xₚ. El ajuste se logra minimizando el error cuadrático medio (MSE).
ŷ = β₀ + Σ βⱼ xⱼ   donde β₀ = intercepto, βⱼ = coeficientes
Solución matricial: β = (XᵀX)⁻¹ Xᵀy  (requiere que X tenga rango completo)
📌
Interpretabilidad
Los coeficientes muestran cómo cambia ŷ por cada unidad de cambio en cada predictor. Fácil de comunicar.
⚠️
Supuestos
Relaciones lineales · Independencia de errores · Homocedasticidad (varianza constante) · Normalidad de residuos
REGRESIÓN POLINÓMICA
¿Cuándo usarla? Cuando la relación entre variables NO es lineal. Amplía la expresividad introduciendo potencias de los predictores (x², x³, ..., xⁿ).
ŷ = β₀ + β₁x + β₂x² + β₃x³ + ... + βₙxⁿ
✅
Ventaja
Permite capturar curvaturas y tendencias complejas que el modelo lineal simple no puede representar.
🔴
Riesgo
Incrementar el grado genera sobreajuste. Tensión sesgo-varianza: bajo grado = alto sesgo, alto grado = alta varianza.
REGULARIZACIÓN — RIDGE Y LASSO
¿Para qué sirve? Estrategia esencial para controlar la complejidad del modelo y evitar sobreajuste. Añade una penalización a la función de pérdida.
🔵
Ridge — L2
Penaliza suma de cuadrados de coeficientes:
Minimiza: RSS + λ Σ β²ⱼ

→ Encoge los coeficientes (los reduce)
→ No anula coeficientes
→ Útil frente a colinealidad
🔴
Lasso — L1
Penaliza suma de valores absolutos:
Minimiza: RSS + λ Σ |βⱼ|

→ Puede anular coeficientes
→ Actúa como selector de variables
→ Produce modelos más interpretables
Hiperparámetro λ (lambda):
· Controla la intensidad de la penalización
· Se ajusta mediante validación cruzada
· λ = 0 → sin penalización → regresión lineal clásica
· λ grande → más penalización → mayor sesgo, menor varianza
· λ pequeño → menos penalización → menor sesgo, mayor varianza
MétodoPenalizaciónAnula β?Uso ideal
Lineal clásicaNinguna (λ=0)NoDatos sin colinealidad ni sobreajuste
Ridge (L2)Σ β²ⱼNoColinealidad entre predictores
Lasso (L1)Σ |βⱼ|SíSelección automática de variables

Regresión Logística y Softmax
▼
REGRESIÓN LOGÍSTICA BINARIA
Diferencia clave: A diferencia de la regresión lineal, la logística está diseñada para resolver problemas de clasificación, no de predicción de valores continuos.
P(y=1|X) = σ(wᵀx + b) = 1 / (1 + e⁻⁽ʷᵀˣ⁺ᵇ⁾)
σ
Función Sigmoide
σ(z) mapea cualquier valor real al intervalo [0,1]. Interpreta la salida como probabilidad de pertenecer a la clase positiva.
⚖️
Parámetros
w = vector de pesos (coeficientes). b = sesgo (bias / intercepto). Los coeficientes se interpretan en términos de log-odds.
Función de pérdida — Entropía cruzada:
L(w) = -Σ [ y log(ŷ) + (1-y) log(1-ŷ) ]
Se minimiza mediante optimización iterativa (gradient descent).
NO es el error cuadrático medio (MSE).
Muy valorada en: ciencias de la salud, economía y marketing por su interpretabilidad y capacidad de generar probabilidades de clasificación.
SOFTMAX — CLASIFICACIÓN MULTICLASE
¿Cuándo usarlo? Cuando el problema incluye más de dos clases (K > 2). Softmax generaliza la regresión logística binaria.
P(y=k|X) = e^(wₖᵀx + bₖ) / Σⱼ e^(wⱼᵀx + bⱼ)   para j = 1 a K
📊
Salida en vector
Cada observación recibe un vector de probabilidades que suma exactamente 1. Se asigna la clase con mayor probabilidad.
🧠
Uso en Redes Neuronales
Es la capa de salida estándar en redes neuronales para clasificación multiclase. Gran eficacia en imágenes y texto.
ModeloClasesFunciónPérdida
Reg. Lineal—IdentidadMSE (error cuadrático)
Reg. Logística2 (binario)Sigmoide σ(z)Entropía cruzada binaria
SoftmaxK > 2 (multiclase)SoftmaxEntropía cruzada categórica

RESUMEN · U2 T1 S1
Lo que debes recordar para el quiz
▼
  • Regresión lineal → predice valores continuos. Regresión logística → predice probabilidades de clase.
  • La solución matricial de regresión lineal requiere que X tenga rango completo para que (XᵀX)⁻¹ exista.
  • Regresión polinómica captura relaciones no lineales, pero a mayor grado → mayor riesgo de sobreajuste.
  • Lasso (L1) puede anular coeficientes → selección automática de variables. Ridge (L2) solo los encoge.
  • Ridge es útil frente a colinealidad. Lasso produce modelos más interpretables.
  • λ = 0 → regresión lineal clásica sin penalización. λ grande → mayor sesgo, menor varianza.
  • La regresión logística usa la función sigmoide. No identidad, no tanh.
  • La función de pérdida en regresión logística es entropía cruzada, NO el MSE.
  • Los coeficientes w en regresión logística se interpretan como log-odds.
  • El parámetro b en logística = sesgo (bias / intercepto). Valor cuando todos los predictores son cero.
  • Softmax → para más de dos clases (K > 2). Produce un vector de probabilidades que suma 1.
  • Softmax es la capa de salida estándar en redes neuronales multiclase (imágenes, texto).
  • Los modelos de regresión buscan el equilibrio entre complejidad e interpretabilidad.
